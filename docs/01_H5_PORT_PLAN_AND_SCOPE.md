# 《小狗探险记》H5翻版迁移方案与范围

> 文档状态：G1 已确认，进入开发  
> 依赖：00_H5_PROJECT_BRIEF.md通过G0

## 1. 迁移原则

H5版以“体验一致、平台解耦、先可玩再完善”为原则。首版不重新设计游戏，也不直接依赖全局`wx`对象；浏览器差异集中放入平台适配层。

```text
共享游戏规则与绘制逻辑
├─ 跑酷玩法
├─ 接飞盘玩法
├─ 商店、每日任务与养成
└─ 数值配置和程序绘制

H5平台适配层
├─ Canvas与屏幕适配
├─ Pointer Events输入
├─ localStorage存档
├─ Web Audio
├─ 页面隐藏/恢复
└─ 分享或复制链接
```

## 2. 页面流程

```text
网页加载与资源预载
→ 点击进入游戏并解锁音频
→ 小屋
→ 活动选择
→ 跑酷 / 接飞盘
→ 结算
→ 再玩一次 / 回小屋 / 分享
```

横屏时不旋转游戏内容，显示“请竖屏体验”的柔和提示；桌面浏览器使用居中的手机比例画布，并支持鼠标拖动。

## 3. 平台能力替换

| 微信小游戏能力 | H5替代方案 |
| --- | --- |
| wx.createCanvas | 页面中的HTMLCanvasElement |
| wx.onTouchStart/Move/End | Pointer Events，必要时兼容Touch Events |
| wx.getStorageSync/setStorageSync | localStorage与JSON序列化 |
| wx.createInnerAudioContext | Web Audio或HTMLAudioElement |
| wx.onHide | visibilitychange与pagehide |
| wx.shareAppMessage | navigator.share，失败时复制当前链接 |
| wx.vibrateShort | navigator.vibrate，可用时调用 |
| 小游戏环境版本 | 构建环境变量控制调试入口 |

## 4. 首版功能范围

### P0

- H5启动页、资源加载状态和音频解锁。
- 手机竖屏、刘海安全区、桌面居中显示。
- 小屋、亲密等级、喂食、玩耍和洗澡。
- 活动选择页。
- 75秒三路线跑酷完整流程。
- 40秒接飞盘完整流程。
- 暂停、继续、返回小屋、结算和重开。
- 骨头币商店及现有五件装扮。
- 每日任务与本地日期刷新。
- localStorage存档和异常降级。
- 静音、切后台暂停。
- 网页分享或复制链接。
- 手机触控与桌面鼠标操作。
- 自动化冒烟测试。

### P1

- 安装到桌面的PWA能力。
- 加载进度细化和离线缓存。
- 分享卡片元信息与渠道参数。
- 数据埋点适配层。
- 存档导出、导入或云存档。
- 正式H5音频和更多浏览器兼容优化。

### 本版不做

- 微信登录、好友排行和开放数据域。
- 现金支付、充值货币和网页内购。
- 未确认渠道的广告SDK。
- 服务端账号系统。
- 与微信小游戏实时双向同步存档。
- 为H5单独重画全套角色与场景。

## 6. 生产顺序

### 第1阶段：可运行骨架

1. 建立H5页面、画布和响应式缩放。
2. 完成浏览器输入、存储、音频、生命周期适配。
3. 加载现有小狗与道具素材。
4. 打通小屋→活动→跑酷→结算→回小屋。

### 第2阶段：玩法完整

1. 移植接飞盘。
2. 移植商店、每日任务和养成。
3. 校准手机触摸阈值、碰撞和帧率。
4. 补齐异常与本地存档迁移。

### 第3阶段：视觉与发布

1. 检查全部页面比例、字体、按钮和装扮锚点。
2. 优化首屏加载、图片体积和音频。
3. 增加网页分享、站点图标和基础说明。
4. 自动测试、手机真机测试和发布检查。

## 7. 预计工作量

- 第1天：H5骨架、平台适配、小屋和跑酷主链路。
- 第2天：接飞盘、养成、商店、每日任务与存档。
- 第3天：视觉校准、音频、分享、适配、测试和可部署包。
- 后续1—2周：PWA、埋点、云存档、渠道接入与运营页面。

三天目标是“功能翻版可发布测试”，不是同时完成新的商业系统。

## 8. 验收标准

- iOS Safari、安卓微信内置浏览器和安卓Chrome至少各完成一次主要流程。
- 首次打开无需注册即可开始。
- 跑酷和接飞盘均可正常完成、暂停、重开和结算。
- 按住滑动不会轻微操作跨越两格。
- 刷新页面后骨头币、装扮、亲密等级和任务进度保留。
- 清空或损坏本地存档时能够恢复默认数据，不阻断启动。
- 切后台不继续计时，返回后等待用户继续。
- 资源加载失败时有可理解的提示或降级，不显示空白页。
- 调试加币入口在正式构建中隐藏。
