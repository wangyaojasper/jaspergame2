# 《小狗探险记》H5版项目立项卡

> 文档状态：G0 已确认  
> 日期：2026-08-30  
> 项目目录：jaspergame2

## 1. 项目目标

将现有微信小游戏《小狗探险记》翻制成可在手机浏览器、微信内置浏览器和桌面浏览器打开的竖屏H5小游戏，同时保持小白狗形象、手绘画风、跑酷、接飞盘、小屋养成、装扮、每日任务和骨头币循环。

## 2. 一句话定位

无需安装、打开链接就能陪小白狗跑酷、接飞盘和布置小屋的轻休闲萌宠H5游戏。

## 3. 目标用户与使用场景

- 6—40岁泛萌宠用户。
- 从公众号、社群、短视频主页、品牌活动页或朋友分享链接进入。
- 单次体验1—5分钟，手机竖屏单手操作。
- 无需注册即可开始，首版优先降低进入门槛。

## 4. H5版价值

- 不依赖小游戏搜索和体验版权限，链接即可传播。
- 可嵌入品牌活动页、公众号菜单和营销落地页。
- 更方便进行玩法试玩、素材投放和跨渠道获客测试。
- 后续可作为宠物品牌联名活动的轻量承载页。

## 5. 首版验证目标

1. 手机浏览器能否稳定完成跑酷和接飞盘各一局。
2. 首次加载后能否在合理时间内进入游戏，触控是否跟手。
3. 浏览器本地存档能否保存骨头币、装扮和养成进度。
4. 分享链接能否带来有效访问和二次游玩。

## 6. 商业化边界

- H5先行版不接支付、充值、红包或强制广告。
- 骨头币仍只通过游玩获得，用于虚拟装扮与后续家具。
- 后续广告需要根据实际分发渠道选择合规的网页广告或渠道SDK，不能直接照搬微信小游戏广告接口。
- 宠物品牌合作作为后续增量，可使用品牌主题、联名装扮或活动页，但不得改变跑酷公平性。

## 7. 技术方向

- 使用原生HTML5 Canvas与JavaScript，保持轻量、启动快、无需大型引擎。
- 使用响应式竖屏画布，设计基准继续采用375×667。
- 使用Pointer Events统一触摸、鼠标和触控笔输入。
- 使用localStorage保存本地进度。
- 使用Web Audio或HTMLAudioElement播放音乐和音效。
- 使用Page Visibility API处理切后台自动暂停。
- 使用Web Share API分享，失败时降级为复制链接。
- 首版为纯静态站点，可部署到任意HTTPS静态托管服务。

## 8. 主要风险

| 风险 | 应对 |
| --- | --- |
| 不同手机浏览器尺寸和安全区差异 | 响应式画布、safe-area适配、真机矩阵测试 |
| iOS音频必须由用户操作解锁 | 首次点击开始时初始化音频 |
| 浏览器清理数据导致存档丢失 | 首版明确本地存档边界，商业版再增加账号或云存档 |
| 微信API和H5 API混杂 | 建立平台适配层，玩法逻辑不直接调用平台接口 |
| 复制两套代码后长期分叉 | 抽离可复用核心模块，H5只实现浏览器启动与平台能力 |
| 图片和音频加载慢 | 预加载首屏必要资源，其余资源延迟加载并压缩 |
